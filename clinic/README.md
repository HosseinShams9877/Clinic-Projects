# دمو — کلینیک زیبایی

دموی استاتیک پلتفرم مدیریت رشد کلینیک زیبایی. برای شروع `index.html` را باز کنید.

## صفحات
- **سایت عمومی:** index · services · service-detail · booking · doctors · about / contact
- **پنل مشتری:** account/login · dashboard · appointments · care · payments · profile
- **پنل مدیر و پزشک:** admin/ (۱۴ صفحه — شامل چرخه درمان، کمپین‌ها، تقویم یادآوری)
- **پنل منشی:** reception/ (۱۰ صفحه — شامل چرخه درمان و تقویم امروز)

## هویت بصری
| توکن | مقدار |
|---|---|
| رنگ برند | `#b56b6b` |
| دکمه اصلی | `#af5d5d` |
| متن برند | `#8e4c4c` |
| پس‌زمینه | `#f7f2f0` |
| سایدبار تیره | `#241c1b` |

رنگ‌ها فقط در `assets/css/brand.css` تعریف شده‌اند. برای تغییر هویت، همان یک فایل را ویرایش کنید.

## بازتولید
این دمو از روی `brands/clinic.json` ساخته شده است:

```bash
cd engine && python build.py clinic
```

> نسخه دمو — بدون بک‌اند. داده‌ها نمونه هستند و پرداخت شبیه‌سازی شده است.
